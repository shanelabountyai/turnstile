| D-28 | **How the cast path reuses the engine.** Hydrate a Phase 1 `Engine` from the event's stored rows (`Engine.hydrate(state)`), run `advance(now)` + the one command in memory, write the delta (new/changed holds, payments, tickets, seats, entries, refunds, order) plus a `CommandLog` row, all in one transaction under `pg_advisory_xact_lock(hashtext(pool_id))` per pool touched.
