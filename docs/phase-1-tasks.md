# Phase 1 — Pure engine + oracle agreement + eval (no database writes)

Nothing is written to the database in this phase. Input is `fixtures/` loaded read-only in memory; output is the `inventory:eval` table and green goldens. No Prisma models beyond the template's, no cast path, no Stripe, no UI. The exit bar is "the TypeScript engine agrees with the Python oracle on every command, every count, every table and the commitment, in any command order." The cloud sandbox may not be able to run Prisma or Playwright; the engine tests need neither, and CI is the gate for everything that does (D-7).
